# Cloud Deployment Notes

Recommended target: Render Web Service.

Why cloud deployment:
- The public URL is stable.
- Students visit the cloud service, not your laptop.
- You can stop exposing your local computer to the public Internet.

Render settings:
- Build Command: `npm install`
- Start Command: `npm start`
- Runtime: Node
- Persistent Disk mount path: `/var/data`
- Persistent Disk size: `1 GB`

Environment variables:
- `NODE_ENV` = `production`
- `DATA_DIR` = `/var/data`
- `ADMIN_PASSWORD` = `mm123456`

Public URLs after deployment:
- Signup page: `https://your-service-name.onrender.com/`
- Admin page: `https://your-service-name.onrender.com/admin.html`

Security notes:
- Share the admin URL and password only with organizers.
- The signup data contains contact information. Do not publish `data/signups.json`.
- If the event is over, pause or delete the cloud service.
- For a custom domain, add it in Render Custom Domains and follow the DNS instructions.

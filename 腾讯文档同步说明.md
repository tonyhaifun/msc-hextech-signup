# Tencent Docs Sync

The site supports syncing every signup to an external webhook.

Environment variable:

`TENCENT_DOCS_WEBHOOK_URL`

When this variable is set, every submitted signup is sent as JSON to that URL.
The local temporary backup is still written first. If the webhook fails, the user
signup still succeeds, and the response includes sync status.

Recommended no-code bridge:

1. Open Tencent Light Link / HiFlow.
2. Create a new flow.
3. Trigger: Webhook / HTTP request.
4. Action: Add a row or record to Tencent Docs.
5. Map these JSON fields to table columns:
   - `id`
   - `createdAtText`
   - `signupType`
   - `teamName`
   - `captainName`
   - `contact`
   - `mainPosition`
   - `canBeAssigned`
   - `membersText`
   - `substitute`
   - `notes`
6. Copy the webhook URL.
7. In Render, add environment variable:
   - `TENCENT_DOCS_WEBHOOK_URL` = the copied webhook URL
8. Manual Deploy -> Deploy latest commit.

The webhook receives JSON like:

```json
{
  "id": "signup id",
  "createdAt": "2026-05-31T00:00:00.000Z",
  "createdAtText": "2026/5/31 08:00",
  "signupType": "队伍报名",
  "teamName": "team name",
  "captainName": "contact person",
  "contact": "wechat or phone",
  "mainPosition": "mid",
  "canBeAssigned": "是",
  "membersText": "1. playerA (中); 2. playerB (上)",
  "substitute": "optional substitute",
  "notes": "notes"
}
```
